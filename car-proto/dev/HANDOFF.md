# CHUBZ: файл состояния

Перезаписывается в конце каждой сессии. Только факты: что стоит, как собрать и проверить, что нельзя трогать.
Истории и рассуждений здесь нет. Проверка файла: новая сессия, которая прочла только его и `RULES.md`, может собрать, проверить и выкатить игру.

Состояние на 24.11.2026: **билд 126, VER 33**.

## Что это и где лежит

- Игра: изометрическая автобоёвка в браузере, кооп P2P. Один файл `car-proto/index.html`, около 8400 строк, Three.js r128 с CDN.
- `car-proto/trystero.js`: сеть для GitHub Pages (WebRTC через публичные релеи).
- `car-proto/assets/`: картинки комикса и карточек (`crew_ref.jpg`, `style_ref.jpg`, `card_layout2.jpg`, `paper_comp.jpg`).
- `car-proto/dev/`: всё для разработки, в игру не подключается.
- Живые копии: https://rokunin.github.io/car-proto/ и артефакт claude.ai «Car Proto — isometric» (публичный).

## Команды

Запускать из `car-proto/dev/`. Нужны python3, playwright, Pillow, npm; ffmpeg для GIF.

| Команда | Что делает | Время |
|---|---|---|
| `python3 harness/build.py` | собирает тест-страницу в `/tmp/chubz-test` | 1 с, первый раз 15 с (ставит three) |
| `python3 run.py` | все тесты, по строке на тест, код выхода 0/1 | около 6 мин (16 с из каждого старта страницы съедает программный WebGL) |
| `python3 run.py -k net -v` | тесты по части имени, с подробным выводом | |
| `python3 booth.py "d.makeHand()"` | фотобудка: модель в игровом масштабе и крупно | 40 с |
| `python3 film.py --setup "<js>" --frames 48 -o x.gif` | покадровая съёмка в GIF и лист кадров | 1.5 с на кадр плюс 25 с старт |

Тесты (`tests/test_*.py`), каждый печатает `ok`/`FAIL` по проверкам:

| Тест | Что проверяет |
|---|---|
| `solo_smoke` | четыре тачки стартуют соло, 4 с игры без ошибок, первый постамент (хало: нова, остальные: спрей) |
| `loot_solo` | доля фазы 280 монет и 70 кристаллов, резерв крупных убийств, капает в банк, мелочь платит целиком или никак, цены 100 и 30, «+» только когда хватает |

| `wanderers` | хало: толпа 21, носителей по числу недостающих скиллов, иконка только над носителями, убитый носитель отдаёт следующий скилл |

Выкат:

1. поднять `const BUILD` в `index.html`; `const VER` поднимать только когда меняется сетевой протокол или состав мира (игроки на разных VER не видят лобби друг друга);
2. `python3 run.py`, всё зелёное;
3. коммит и пуш в `master`: GitHub Pages обновится сам;
4. артефакт: опубликовать тот же `index.html` новой версией (slug `41699404-7f76-441e-a340-da0d02f7bedb`, последняя версия `1795530055-7744`).

## Соглашения в коде

- Камера: изометрия, ортографическая. Вправо по экрану это мир `(1,0,-1)/√2`, вниз по экрану `(1,0,1)/√2`. Камера стоит со стороны `+x,+z`.
- Сеть: хост считает всё. `netEv(d, to)` заворачивает событие в `{...d, g: NET.game}`, поэтому **поле `g` в событиях занято**. Обработчик получает `from` (id пира); удалённого игрока искать перебором `NET.remotes.values()` по `String(q.peer) === String(from)`.
- Presence-поля удалённого игрока: `ak`, `ks`, `gd`, `tw`, `pp`, `vw`/`vh`.
- Биты флага монстра в снапшоте: 1 flash, 2 mini, 4 gate, 8 stun, 16 dig, 32 wb, 64 rig, 128 guard, 256 wbLoot.
- Случайность: `Math.random` подменён сидированным генератором (`seedRandom(SEED)`), один на весь мир. Новый вызов в генерации сдвигает всё, что создаётся после него.
- Фазы: `PHASES` roll, scout, save, hell, boss; `PH.i` текущая, `PH.brk` пауза перед волнами.

## Что стоит

**Постаменты** (у каждого игрока свои, это решение Романа). `pedestals[]`, `addPedestal(k, x, z)`, состояния dormant → rising (ближе `PED_RISE_R = 25`) → sealed → open → gone. Порядок: первая пушка у центра (`firstGun()`: хало нова, остальные спрей), затем две оставшиеся пушки далеко. Постамента прыжка нет: прыжок у всех с первой секунды. У каждого засада `ambush(x, z, big)`: 13 или 18 мелких и мини-босс с меткой `m.guard`. Щит падает, когда в радиусе `PED_GUARD_R = 32` не осталось живых с меткой `guard`.

**Блуждающие боссы.** Когда `crewArmed()` (у всех три пушки и прыжок), один раз `spawnWanderers()`: толпа `WB_CROWD = 21`, лут несут только некоторые (`m.wbLoot`), `wbTopUp(dt)` держит носителей по числу недостающих скиллов. `bossDrop(x, z)` роняет каждому его следующий скилл отдельным предметом. Носитель отмечен: над ним иконка скилла, который он несёт мне (`updateWbMarks`, `wbGift()`), указатель «★» и золотая точка на миникарте только у носителей; остальная толпа видна красными точками.

**Смерть.** `deathToll()` снимает случайный уровень прокачки, а если прокачки нет, случайный скилл или пушку (прыжок не теряется). Потеря показывается иконкой, которая тлеет и разваливается (`lossFxStart`, `lossShatter`, `updateLossFx`).

**Бревномашины.** `RIG = { speed 2.6, half 18.75, mastR 5.6, spin 0.85, n: { roll 2, scout 6, save 6, hell 10, boss 0 } }`. `makeRig(m)`, `rigAI` (патрулирует 22 м от дома, сторонится других машин), `rigTick`, `rigToss` (бросок 5 по горизонтали, 10 вверх, 8% хп, пауза 1.8 с), `spawnRig()` (у постаментов и алтарей, не ближе 90 м к другой машине), `rigBreak(m, quiet)`. Пули по ним не работают. Полоска хп над мачтой.

**Бомбы.** `TNT = { grab 3.4, help 8, g 32, vy 20, near 6, far 17, aim 0.6 }`. Бомба едет на тележке, вдвоём быстрее (`towK()`), прыжок с бомбой бросает её (`throwBomb()`), попадание в кабину снимает треть, три убивают. После попадания `bombRefill(by, m)` кладёт следующую со стороны бросавшего, не ближе конца бревна. Обычный спавн: пока `rigs.length > bombs.length`.

**Рука.** `HAND = { arrive 1.5, hold 0.45, leave 1.0, far 62, S 1.7, ink 0.2 }`, `handAxis = (0.26, 0.63, -0.74)`, `makeHand()`, `handTick(B, dt)`, позы пальцев в `HAND_F` (несёт / раскрыта), точка щепоти `handOff`. Бомбу в руке взять нельзя, указатель пишет «bomb incoming». Образец вида: `refs/glove_concept.jpg`.

**Лут.** `LOOT = { coins [280,190,170,160,100], gems [70,45,40,35,20], abCost [100,200,300], wCost [30,60], drip [300,150,150,120,60], big 0.55 }`. Доля фазы на игрока делится: 55% в резерв крупных убийств `lootBig` (мини-босс 12 монет и 2 кристалла, блуждающий 5 и с шансом 2, бревномашина 25 и 15, босс 40 и 15), остальное из `lootDue` капает в `lootBank` за `drip` секунд (ящик 3–5 монет и с шансом 2 кристалла, брут 3–4, моб 1–2 и только когда в банке от 8). Крупное убийство берёт из резерва, потом из банка, сколько есть; мелочь платит целиком или никак. При смене фазы недокапавшее сразу падает в банк. Монетная доля игрока считается от цены его скиллов (`coinW`): паук 3/4. `lootLeft()` остаток всех трёх горшков. `lootFrom(kind, x, z)`: mob, crate, enemy, mini, wb, rig, boss. Подбор решает хост: клиент шлёт `lootget`, хост отвечает `lootok` с полем `gm` (0 монета, 1 кристалл). Скиллы качаются монетами (`abPrice`), пушки кристаллами (`wPrice`). Кошелёк `#wallet`. За забег на игрока 900 монет из 1200 нужных (у прыжка три уровня за 600, у остальных скиллов по два за 300) и 210 кристаллов из 270.

**Прыжок.** Есть у всех со старта, качается до трёх уровней (`abMax`), на нулевом просто давит то, на что приземлился. Прокачанный зовёт `landPower(lv)`, у каждой тачки своё:
- багги, `stomp` (`STOMP r [7, 8.5, 10]`): ур. 1 оглушает стреляющую мелочь на 1.5 с, ур. 2 снимает мелочи половину хп и оглушает на 2 с, ур. 3 убивает мелочь и оглушает на 2 с всё, что крупнее (Пирамидона нет);
- паук, `spawnBrood` (`BROOD n [6, 10, 10]`): плоские паучки разбегаются по мобам, сидят на мелких, ползают по крупным, замедляют 3 или 4.5 с; на ур. 3 в конце взрываются на 3 урона;
- хало, `spawnSpikes` (`SPIKE n [6, 11, 18], r [3, 5, 7.5], T [1.3, 2.6, 4]`): шипы света бьют раз в 0.4 с по 1 урону, на ур. 3 по 2;
- единорог, `starburst` (`STARB n [10, 16, 24], reach [9, 13, 17]`): кольцо мелких пуль.
Мелочь это `isFry(m)`: не мини-босс, не блуждающий, не машина, не heavy. Клиент просит хоста событиями `stomp` и `slow`; картинку друзьям несёт `jfx`.

**Кубы хало.** Три (с прокачкой пять) на 8 с: висят у тачки, выбирают жертву, встают на дыбы 0.24 с, пикируют и взрываются (`cubeBoom`): мелочь насмерть, крупному 3, соседям в 2.6 м по 1. До пяти пике на куб.

**Экран выбора тачки.** Комикс снят (код `CrewArt` остался). Вместо него четыре карточки `RIDE_CARD`: настоящий рендер тачки, как она ездит, скиллы с иконками и клавишами. Клик по карточке выбирает и стартует.

**Спрей хало.** Пуль на 30% меньше, чем у багги (2/4/6 против 3/5/9), урон пули тот же, скорость 66 против 70. Других штрафов нет.

**Указатели.** `updateHints`: подсказки с одним `grp` в пределах 260 px у края сливаются в одну с `×N`, показываются три ближайшие кучки.

**Музыка в игре.** `MUSIC`: партитура массивами `A`, `B`, `SEC`, `FORM`, темпы `BPM = [132,144,156,168,172]`, уровни аранжировки `VAR`, планировщик `MUSIC.tick()`, клавиша M. Аранжировка риффов в игре старая.

**Офлайн-музыка.** `music/score.py` (ноты, темп 133) и `music/mix.py VARIANT` (всё синтами, слои по розовому шуму, сайдчейн, EQ по эталонной кривой, «радио»). Нужны mido, tinysoundfont, numpy, scipy и саундфонт GeneralUser-GS (`git clone https://github.com/mrbumpy409/GeneralUser-GS` в `/tmp/sf/gu`). Принятый Романом вариант: A с плавными аккордами в интро (`chubz_king_A2.mp3`, в репо не лежит).

**Картинки.** `tools/nanogpt_gen.py MODEL PREFIX N "prompt" refs...`, ключ в переменной `NANOGPT_KEY`. `nano-banana-pro` отдаёт картинку сразу, 0.14 $ за штуку. `gpt-image-2` отдаёт ссылку, которую песочница не скачивает.

## Принято, не менять без слова Романа

- Перчатка билда 124: три пальца и большой, щепоть за фитиль, белая, жирная тушь, без рукава.
- Постаменты у каждого свои, с серьёзной дракой у каждого.
- Прыжок у всех со старта; у прыжка три уровня со своим эффектом на каждую тачку (слова Романа от 24.11.2026).
- Бревномашине нужно три бомбы; машины не стоят ближе 2.4 длины бревна.
- Блуждающих боссов 21.
- Залп спрея у хало на 30% меньше, чем у багги, на каждом уровне (сейчас 2/4/6 против 3/5/9); это весь штраф.
- Монеты и кристаллы сыплются десятками, цены в сотнях и десятках.
- Музыка: вариант A, всё синтами, темп постоянный.

## Известные слабые места

- Паук в бот-тесте попал бомбой 1 раз из 8. Причина не выяснена.
- Пыль при постановке бомбы почти не видна под ладонью.
- Тушевой контур есть только у перчатки: помощник `inked()` живёт внутри `makeHand`.
- В коде остался хвост прежней схемы прокачки: `upPts`, `upGot`, `UP_MAX` и предмет `upgrade`, который больше ниоткуда не падает.

## Ловушки

- Имя `BOMB` занято единорогом, константы бомб называются `TNT`.
- Соло-респаун и смена роли в сети чистят рой: всё, у чего есть отдельная модель (машины), надо ломать через `rigBreak(m, true)`, иначе модель остаётся без монстра.
- Бомба без живой бревномашины удаляется в тот же кадр. Для съёмки руки сначала `spawnRig()`.
- `d.addBomb(...)` кладёт бомбу без руки, если четвёртый аргумент не `true`.
- В `ev()` харнесса аргумент называется `a`: в теле не объявлять свою `a`.
- Имя `waves` занято директором волн; кольца приземления лежат в `landWaves`.
- Тачка стреляет сама: в тесте урона сначала `d.fireCooldown = 1e9`, иначе мобов убьёт пушка.
- Страница в headless отвечает через 16 с после загрузки, хотя скрипт игры готов за 2 с. `game.py` ждёт `commit`, а не `DOMContentLoaded`.
- Под swiftshader картинка рисуется медленно. Логику проверять в режиме `fast`, картинку снимать с замороженными часами.
- Ссылки на картинки `gpt-image-2` живут сутки и открываются только через браузер.
