# CHUBZ (car-proto-next)

Before any work on the game read `dev/HANDOFF.md` (what stands, commands, traps), `dev/RULES.md` (how to work, Roman's words), `GLOSSARY.md` (the game's words) and the decisions in `docs/adr/` (do not re-litigate an accepted one without a new reason; record a new hard-to-reverse decision there, format in ADR-0001). The plan for the architecture work is `docs/ROADMAP.md`.
The game's sources are `src/` (`legacy.js` wires the modules together, the game's code is in the folders beside it; `three.js`, the HTML shell `index.html`). `npm run build` writes the single `car-proto-next/index.html` that players get, live at https://rokunin.github.io/car-proto-next/: it is a build result, never edit it by hand, and commit it together with the `src/` change it comes from (CI checks they match). The build number is the `chubz-build` meta in `src/index.html`. The published game at https://rokunin.github.io/car-proto/ (`../car-proto/`, build 134) is frozen until the roadmap is done (Roman, 25.11.2026): do not touch it unless Roman asks for an urgent fix there. The claude.ai artifact also stays on build 134. Setup: `npm ci`. Tests: `cd dev && python3 run.py` (builds the test page from `src/` itself). Lint: `npx biome ci src`.
At the end of a session rewrite `dev/HANDOFF.md` to the new state.
