# Хост решает за мир, гостям верим

Игра кооперативная, поэтому защиты от читов нет намеренно. Хост ведёт монстров, лут, фазы и здоровье босса и рассылает итог; гость показывает свои попадания сразу и отправляет их хосту, хост их принимает без проверки (с ограничением размера посылки). Здоровье Пирамидона с билда 132 считает только хост, потому что раздельный счёт у каждого игрока при порванной связи убивал босса на четверти. Если появится соревновательный режим, это решение пересматривается первым.
