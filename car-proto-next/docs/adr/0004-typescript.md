# Вынутые модули пишем на TypeScript; проверяет TypeScript 7

Vite собирает `.ts` без отдельного шага, а типы ловят то, что сейчас ловят только тесты: опечатку в имени, неверный аргумент, забытое поле в сетевом событии. TypeScript 7 вышел 8 июля 2026: нативный компилятор, примерно в 10 раз быстрее шестого. В `.ts` переходит только модуль, вынутый из `legacy.js`, и только после обновления Three.js (ADR-0005), чтобы не писать типы под r128. В `tsconfig` явно задаём `strict: false` и `types` (в 7.0 значения по умолчанию другие), `noImplicitAny` включаем по модулю, когда он покрыт тестами. `tsc` используем только из командной строки: стабильного программного API у 7.0 нет.

Lint и формат — Biome 2: один быстрый инструмент вместо ESLint и Prettier. `legacy.js` Biome не переформатирует (иначе пропадают история строк и все якоря харнесса), для него включены только правила корректности, в первую очередь необъявленные переменные: в модуле они падают только во время игры.

## Рассмотренные варианты
- JavaScript с JSDoc и `checkJs`: TypeScript 7 выкинул старые Closure-приёмы JSDoc (`@enum`, `@class`, `function(string): void`); обычный JSDoc работает, но перед `.ts` выигрыша нет.
- Без типов: дешевле при переносе, дороже при каждой следующей правке.
