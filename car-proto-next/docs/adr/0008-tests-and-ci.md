# Харнесс на Python остаётся; хуки — честные швы в коде; CI на каждый пуш

Харнесс на Python Playwright (15 тестов, реальные бои с ботом, турбо) работает и знает игру; переписывать его на другой раннер — недели без пользы. Сейчас `harness/build.py` вклеивает отладочные хуки в HTML по строковым якорям. Пока игра — один `legacy.js`, отдельный модуль до её переменных не дотянется, поэтому заменяем вклейки по частям: часы кадра и выключатель рендера становятся настоящими швами в коде игры, мок сети и часы `__hx` ставятся через `add_init_script` Playwright, а вынутые модули регистрируют себя в отладочном реестре за флагом сборки. Плюс один дымовой тест гоняет именно тот `index.html`, который уходит игрокам.

Юнит-тесты Vitest проверяют чистые модули (данные, лут, формулы баланса, расклад кругов). GitHub Actions на каждый пуш: сборка, Biome, типы, юнит-тесты, быстрый набор харнесса, совпадение закоммиченного `index.html` со сборкой (Node и lockfile закреплены) и поиск секретов (gitleaks); полный набор и реальные бои — по запросу.
