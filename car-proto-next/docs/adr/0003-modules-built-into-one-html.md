# Исходники — модули в `src/`, сборка — один `index.html` без минификации

Сейчас игра — один файл на 9 000 строк, и правки строковой заменой дважды ломали код (комментарий съедал конец строки). Предлагаем держать код ES-модулями в `car-proto/src/` и собирать Vite 8 с плагином `vite-plugin-singlefile` в тот же единственный `car-proto/index.html`. Three.js и Trystero входят в сборку из npm: одна точка загрузки, нет зависимости от CDN и его CSP ни на Pages, ни в артефакте, харнессу не надо подменять ссылки. Собранный файл коммитим, как сейчас, но без минификации: тогда диф коммита остаётся читаемым, история не раздувается от перемешанного кода, а `index.html` по-прежнему можно открыть и прочитать. В `CLAUDE.md` пишем, что `index.html` — результат сборки и руками не правится.

Переезд идёт «удушением»: сначала весь нынешний скрипт становится одним модулем `src/legacy.js`, потом из него по одному вынимаются модули. Первый шаг не обходится без правок (их нашёл ревью Fable 5.2 25.11.2026): номер билда переезжает в `<meta>` (проверка обновления ищет `const BUILD` в тексте страницы), проверки `THREE.EffectComposer` и `THREE.FXAAShader` заменяются импортами из `three/addons`, аудио-воркер, собранный из `audioLib.toString()`, получает отдельный файл, `import('./trystero.js')` — путь сборки, `assets/rubber_riffs.mp3` остаётся внешним файлом. Глобальные `let`, которые меняют разные части кода, при выносе модулей переезжают в объекты состояния: импорт в ES-модуле нельзя переприсвоить.

## Рассмотренные варианты
- Оставить один файл: дешевле сегодня, но каждый следующий месяц правок дороже и опаснее.
- Минифицированная сборка: на 30–40% меньше, но каждый билд переписывает весь файл в истории и убивает читаемость; сжатие gzip на Pages и так забирает большую часть разницы.
- Деплой сборки через GitHub Actions вместо коммита: требует переключить Pages этого пользовательского репо на Actions и усложняет выкладку в артефакт. Вернуться, если история всё же начнёт раздуваться.
- ECS (koota, bitECS): игра держится на массивах объектов и функциях обновления; переход на ECS — переписывание без выгоды для игрока.

Сделано в сборке 137 (25.11.2026), с тремя поправками. Vite 8 собирает через Rolldown, а тот печатает код заново: обычные комментарии выпадают, отступы становятся табами, неиспользуемое вырезается. Поэтому `index.html` читается, но комментарии и якоря тестов живут только в `src/`, и харнесс собирает тест-страницу из `src/` той же сборкой (вклейки идут в копию `legacy.js`). Trystero до шага 4 остаётся прежним файлом рядом со страницей: сеть не меняется вместе со сборкой. Аудио-воркер пока собирается из `audioLib.toString()`: без минификации сборщик не трогает имена внутри функции, а отдельным файлом он станет вместе с модулем звука. Номер билда — `<meta name="chubz-build">`; рядом комментарий `const BUILD = N`, по которому страницы билда 136 и старше узнают об обновлении.
