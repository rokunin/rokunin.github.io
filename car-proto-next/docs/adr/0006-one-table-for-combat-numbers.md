# Все боевые числа — в одной таблице данных

Числа оружия, скиллов, прыжков, мобов, волн и боссов сейчас разбросаны по коду; для баланса пришлось вручную выписать их в `dev/balance/FACTS.md`, и эта копия начнёт врать после первой же правки. Выносим их в `src/data/` (по файлу на ride, оружие, монстров, волны, боссов). Сборка выгружает их в `dev/balance/data.json`, модель баланса и тесты читают оттуда. Правка баланса — правка одной таблицы, а модель всегда считает по тем же числам, что и игра. Хеш таблицы входит в версию сетевого протокола: игроки с разными числами баланса не попадут в одно лобби, даже если `VER` забыли поднять.

Сделано в сборке 142 (25.11.2026), первая часть. В `src/data/` (world, weapons, rides, monsters, waves, bosses, economy) переехали без изменений все таблицы, что были в коде (W_STATS, SW_KINDS, STOMP, SPIKE, LOOT, BOSS2, PHASES и другие, 40 штук), и разбросанные числа, которые повторяла модель баланса: пули по тачкам, паутина, мечи хало, лучи, бур. `npm run build` выгружает их в `dev/balance/data.json`, `sim.py` читает их оттуда (вывод модели не изменился ни на цифру), CI сверяет `data.json` со сборкой. `VER` стал строкой `'38.' + DATA_HASH`. Остальные числа из кода (лут по источникам, злые кубы, формулы мини-боссов, совместная игра, директор волн, физика прыжка) переезжают в таблицы вместе с модулями на шаге 3; `FACTS.md` остаётся снимком сборки 133 до тех пор.
