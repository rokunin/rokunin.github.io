# Архитектура и инфраструктура: план

Основа — ADR 0003–0010 (`docs/adr/`). Порядок и оценки поправлены по ревью Fable 5.2 от 25.11.2026. Каждый шаг заканчивается зелёным полным набором тестов и выкаткой. Поведение игры не меняется, пока шаг этого не объявляет. Сессия здесь — одна рабочая сессия агента с прогоном тестов.

## Шаг 0. Мир и сборка (2–3 сессии)
- Свой генератор случайных чисел для мира и тест «отпечаток мира» (ADR-0009). Делается первым, на нынешнем файле.
- `package.json` с закреплёнными версиями, Vite 8, `vite-plugin-singlefile`, Biome 2 (для `legacy.js` только правила корректности), Three.js r128 и Trystero из npm в нынешних версиях.
- Скрипт → `src/legacy.js`, HTML-оболочка и CSS → `src/`; правки из ADR-0003: номер билда в `<meta>`, аддоны Three импортами, аудио-воркер файлом, путь Trystero, музыка внешним файлом. Сборка без минификации.
- Харнесс: часы и рендер — швы в коде, мок сети и `__hx` через `add_init_script`; `build.py` уходит. Дымовой тест на выкатываемом `index.html`.
- GitHub Actions: сборка, Biome, юнит- и быстрые тесты, совпадение `index.html` со сборкой, gitleaks.
- `window.onerror` и `unhandledrejection` пишут в общий журнал диагностики лобби (он уже есть); молчаливые `catch (e) {}` получают запись в журнал.
- Эталонные кадры на r128.
- `CLAUDE.md`: `index.html` — результат сборки.

## Шаг 1. Three.js r128 → r187 (2–3 сессии + взгляд Романа)
- Остановки r151 → r164 (цвет) → r164 (свет) → r187, на каждой сверка с эталоном (ADR-0005).
- Роман смотрит итог на своей видеокарте и телефоне.

## Шаг 2. Таблица боевых чисел (1–2 сессии)
- `src/data/` (ADR-0006), выгрузка `dev/balance/data.json`, `sim.py` читает её, `FACTS.md` уходит. Хеш таблицы — в версию протокола.

## Шаг 3. Модули (8–12 сессий)
- От листьев к центру: звук и музыка → текстуры и вшитая графика (base64 → файлы, которые сборка вшивает сама) → интерфейс → сеть (у комнаты уже два адаптера: p2p и артефакт) → враги → машинки и скиллы → фазы и мир → цикл.
- 52 общих `let` → объекты состояния. Вынутый модуль → `.ts` (ADR-0004), юнит-тесты Vitest.
- Сохранения `localStorage` получают версию схемы.

## Шаг 4. Сеть (2–3 сессии + аккаунт Cloudflare Романа)
